Project Architecture Doc（项目架构与模块结构）

多语言项目架构分析工具：6 个 Python 机械臂先行提取确定性数据（技术栈/模块清单/目录树/依赖关系/分层模式/外部集成），AI 只补描述列。支持 Java/PHP/Python/Go/Vue/React 全栈，大项目零幻觉。

执行全流程（7 步·6 机械臂 + AI 组装）

00 技术栈自动检测
命令
python3 scripts/project_scanner.py /path/to/project
产出
JSON：language / framework / build_tool / is_monorepo / is_fullstack。
动作
AI 从不用猜技术栈。检测完一句话告知：「检测到 Java Spring Boot 项目，Maven 构建，共 3 个子模块 + 1 个 Vue 前端。开始扫描。」
01 模块/服务清单提取
命令
python3 scripts/module_finder.py /path/to/project
动作
自动解析构建文件（pom.xml/go.mod/package.json/composer.json/pyproject.toml），输出每个模块的名称、类型（业务/基础/前端）、构建工具、端口。
02 智能目录树
命令
python3 scripts/dir_tree.py /path/to/project --depth 3
动作
按技术栈自动过滤无关目录（node_modules/vendor/venv/.git/target/dist），最多 3 层，输出 Markdown 树 + 目录约定说明。
03 依赖关系分析
命令
python3 scripts/dep_analyzer.py /path/to/project
动作
解析模块间构建依赖 + 跨服务调用（扫描 HTTP Client/RestTemplate/Feign/axios/gRPC）。输出 Mermaid 依赖图数据 + 循环依赖警告。
04 分层架构与设计模式检测
命令
python3 scripts/layer_detector.py /path/to/project
动作
按技术栈规则识别分层层级（MVC/DDD/三层）+ 常见设计模式（Factory/Strategy/Observer/Builder/DI）。输出文件名:行号作为证据。
05 外部集成扫描
命令
python3 scripts/integration_finder.py /path/to/project
动作
扫描配置文件和客户端代码，汇总 DB（MySQL/PostgreSQL/MongoDB）、Cache（Redis）、MQ（RabbitMQ/Kafka）、存储（OSS/S3）、第三方 API 使用分布。
06 AI 组装文档
动作
拿到 6 个 JSON 后，AI 按 references/output-template.md 填描述列、组装 Mermaid 图、输出最终文档。
Gate
◆ 不可编造：JSON 中没有的模块/依赖/模式，不得凭空添加。
产出
.ai-workflow/doc-project-architecture/项目架构与模块结构.md（6 章）。
