Container Delivery Playbook（多中间件离线交付）

多中间件通用离线交付方法论：交付包四件套 + test/prod 双工程产出 + 三中间件高可用架构 + 四级自检 + 盲盒日志排障闭环。数据库/缓存/搜索引擎任意中间件，打包成运维只执行两条命令的傻瓜式交付包。v3.1 新增盲盒日志与危险操作分步确认。

执行全流程（6 步）

01 打包机环境判断（构建第一步）
动作
uname -m 识别架构：Intel Mac/Linux x86_64 → 直接 docker build；Apple Silicon M5(arm64) → 默认 --platform linux/amd64（QEMU 模拟）。目标恒为 amd64。
红线
识别逻辑必须是构建脚本第一步；导出前必须架构自检（docker image inspect Architecture=amd64），防 arm64 镜像误传 🔴。
02 构建交付包四件套
软件
离线运行时（下载脚本 + 官方校验和），目标服务器零预装 🔴
镜像
自定义镜像固化 ENTRYPOINT，构建机架构自动对齐目标机 + sha256 🔴
配置
环境模板入库，真实值本地填；凭据文件不入库（模板 + gitignore）🔴
脚本
公共库抽自检/校验，幂等可重跑 🟡
03 双工程产出（test / prod）
test 工程
单机拓扑：每中间件 1 台，多中间件同机共存。阶段 2 退化为仅初始化 + 连通验证。
prod 工程
3 节点高可用：每中间件 3 台 + 主从/集群。阶段 2 自动组网 + 配置主从 + 故障转移演练。
规则
镜像构建产物两工程共享，差异只在 config/scripts。环境差异在生成期固化，test 不可能误用于 prod 🔴。
04 两阶段编排部署
阶段 1（每台，可并行）
自检 → 装运行时 → 导镜像 → 起容器 → 节点自检。
阶段 2（部署机，一次）
连通预检 → 密钥互信 → 组网/主从 → 初始化 → 验证。test 工程阶段 2 仅初始化。
角色差异
统一引导式脚本逐组件给角色建议（master:必须/worker:跳过），未声明角色拒绝执行。
05 四级自检
前置硬失败
架构、磁盘 ≥ 预分配、端口空闲、宿主端口冲突 → 🔴 exit 1 + 自动修复选项
软警告
时间同步 → 🟡 提示继续
过程校验
运行时、镜像导入、容器 RUNNING、关键进程 → 🔴 逐条退出码检查
后置验证
服务 ACTIVE、主从角色、连通性 → 🔴 失败不打印「成功」
06 盲盒日志与排障闭环
分类
每步日志按错误类型分文件（download/install/image-load/network/service/health/cluster…），从 stderr 尾部启发式匹配「可能原因 + 验证命令」。
索引
index.md 步骤状态表（每步 RUNNING→✓/✗），进程崩溃由 EXIT trap 自动标记卡死点。
collect
一键打 collect-<ts>.tar.gz → scp 回开发机 → 开发机 LLM 按 index→errors→step log 定位改代码。
铁律
禁 || true 吞错；危险操作（build/import/run/apply/rm/push）用 confirm_risk 包裹。

三中间件高可用架构

数据库（OceanBase 类）

  • 内置 Paxos 3 副本，Leader 写 + Follower 读
  • 自动选举（<8s），多数派 RPO=0
  • 端口：2881 SQL / 2882 RPC / 2883 代理
  • 应用：1 个入口，切换无感知

缓存（Redis 类）

  • 主从复制 + 哨兵（1 主 2 从 + 3 哨兵）
  • 哨兵投票（quorum=2）自动提升从库
  • 端口：6379 数据 / 26379 哨兵
  • 应用：哨兵模式，代码需改一次（直连→哨兵）

搜索引擎（ES 类）

  • 集群 + 副本分片，每节点 master+data
  • 内部自动选举 + 副本分片提升
  • 端口：9200 HTTP / 9300 节点间
  • 应用：任意节点 :9200，代码零改动

关键信息

触发条件

  • 内网/无外网服务器，离线交付中间件
  • 单机测试（每中间件 1 台）
  • 3 节点高可用生产（每中间件 3 台）
  • 想要「本地打包 → 上传 → 一键启动」体验

排除边界

  • 多容器编排器场景（K8s 完整集群）
  • 具体中间件深度调优
  • 在线环境部署

产出物

  • test-工程/（单机 + 每中间件交付单元）
  • prod-工程/（3 节点高可用 + 每中间件交付单元）
  • 每工程含 README + software/images/config/scripts + checksums

离线交付红线

🔴 三条红线

  • 架构一致性：arm64 自动强制目标平台 + 导出前架构自检
  • 传输完整性：sha256 校验和 + 上传后比对（双工具兼容）
  • 凭据不入库：环境文件仅占位符模板，落盘 600
